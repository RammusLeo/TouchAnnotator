| Component | Source | Handling |

The code license does not relicense model weights or MANO assets. The public source archive excludes third-party binaries. The released student checkpoint contains Qwen-derived parameters. The model repository retains the upstream Qwen license notice as `QWEN_LICENSE`; component terms continue to apply. No training data, raw recordings, credentials, or paper PDF are copied into the source release.
