# Visual assets

The figures are extracted from the author-provided manuscript *TouchAnnotator: Multi-Source Tactile Supervision with Privileged-View Distillation* (3879.pdf).

| Asset | Manuscript source |
| --- | --- |
| `paper/overview.png` | Fig. 1, page 2; schematic heatmaps |
| `paper/method.png` | Fig. 2, page 4 |
| `paper/egotouch-results.png` | Fig. 3 upper panels, page 7 |
| `paper/fpha-results.png` | Fig. 3 lower panels, page 7 |
| `paper/measured-recordings.png` | Fig. 4, page 8 |
| `paper/cross-embodiment.png` | Fig. 5, page 9 |
| `brand/mark.png` | Original touch icon embedded in Fig. 1 |
| `brand/logo.svg`, `brand/logo.png` | Editable vector redraw inspired by the paper's touch icon, paired with a new wordmark |
| `brand/capabilities.svg`, `.png` | Release capability labels |

Figures were rendered from their original PDF regions at 4× resolution, retaining labels and comparison order. Captions and page context are represented in the README. No numerical predictions were altered. Coordinates are recorded in `paper/provenance.json`.

PNG versions are used in the README for consistent rendering across Markdown viewers. SVG sources remain available for future resizing or branding adjustments. The complete paper PDF is not included.
